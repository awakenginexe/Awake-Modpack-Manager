== Awake Native Core helper (core-host/windows-x64/awake-core-host.exe) — GPL-3.0-only ==
awake-core-host.exe (Awake Native Core 0.2.1, protocol 2.0 with the manager.v0.2.1 extension) is
built from the Awake Launcher repository, directory native-core/, at commit
b06c9a804503545207bacfa3bfdf8bfe23604e07 (branch feat/native-core-manager-020). It is a separate
program that the Manager starts and talks to over a local named pipe.
Copyright (C) Awake Launcher contributors and the upstream projects listed in
core-host/windows-x64/COPYING.md (shipped next to the executable).

Complete corresponding source code (including the vendored libraries and build files) is
published with every Awake Modpack Manager release that ships this helper, as
awake-core-source-b06c9a804503.zip (SHA-256 543dcc404bdb9bb6f319dceb6e860b1040a7c55611fba5443d934444237503ee):
https://github.com/awakenginexe/Awake-Modpack-Manager/releases. Its BUILD-AND-REDISTRIBUTE.md and
SOURCE.json are authoritative for the build; reproducible builds are not claimed.
Build: cmake -S native-core -B <build> -G Ninja -DCMAKE_BUILD_TYPE=Release
  "-DCMAKE_PREFIX_PATH=<Qt 6.11.2 msvc2022_64>;<vcpkg x64 prefix>" -DBUILD_TESTING=OFF,
  then cmake --build <build>, then native-core/deploy.ps1 -Executable <build>/awake-core-host.exe
  -QtBin <Qt>/bin -DependencyPrefix <vcpkg x64 prefix> -Destination <dir>.
  Toolchain: MSVC 2022 x64. See docs/modpack-manager/handoff.md in the source archive.
SHA-256 of every shipped helper file: core-host/windows-x64/SHA256SUMS (the helper package's own
manifest, also embedded in the Manager, which refuses to start a changed or extended helper folder)
and core-host/windows-x64/HELPER-SOURCE.txt.
Licence: GNU General Public License v3.0 only (LICENSE in this installation).

The helper statically links these archive libraries (to read modpack ZIPs). Their full licence
texts ship in core-host/windows-x64/licenses/:
  libarchive (BSD-2-Clause and related permissive terms)  licenses/libarchive.txt
  zlib (zlib licence)                                      licenses/zlib.txt
  bzip2 / libbzip2 (bzip2 licence, BSD-style)               licenses/bzip2.txt
  liblzma / XZ Utils (0BSD / public domain parts)           licenses/liblzma.txt
  zstd (BSD-3-Clause; dual-licensed BSD or GPLv2, used under BSD) licenses/zstd.txt
