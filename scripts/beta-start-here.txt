Awake Modpack Manager for Windows x64

1. Download Awake-Modpack-Manager-<version>-Windows-x64-Setup.exe and check it against SHA256SUMS.txt on the release page.
2. Run the installer. It installs or updates the app for your Windows user and keeps your projects. The Native Core helper is included.
3. Start Awake Modpack Manager from the Start menu. Later versions are offered inside the app.
4. To play, install Awake Launcher, then choose Open in Awake Launcher on a project card.

Portable ZIP: extract it to its own writable folder and run Run-Manager.cmd. It needs Microsoft Edge WebView2 already installed, and is updated by downloading a newer ZIP.

The apps and helper are not code-signed, so Windows may show a SmartScreen warning.
