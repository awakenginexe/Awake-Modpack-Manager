## Verification done for v0.1.0

* The bundled helper is byte-identical to the package Codex built and handed off from
  `299c140bd` (exe SHA-256 `d4b01dbe29f550e6514f5d7db1a1d60418f958a9d450cfd202acf526551c310c`); it
  reports Native Core 0.1.1, matching that commit's `native-core/main.cpp`. The Manager did not
  rebuild the helper itself, so bit-for-bit reproducibility of the binary is not independently
  proven.
* The published source archive contains every file of commit `299c140bd` with identical content
  (2,155 files; line endings normalised) plus the vendored libraries needed to build it.
* `scripts/stage-helper.mjs` stages the whole 18-file package and records a SHA-256 for each file;
  `npm run desktop:build` refuses a missing, modified or stub helper.

## Rules for contributors

* Code copied from Awake Launcher (GPL-3.0) is allowed; keep its notices.
* Keep Qt dynamically linked and replaceable; update the Qt version and source link when the
  helper is rebuilt with another Qt.
* Re-run `cargo about generate about.hbs -o ../licenses/rust-crates.txt` (in `src-tauri`) when
  Rust dependencies change, and update `THIRD-PARTY-NOTICES.txt` when npm runtime dependencies
  change.
* Never commit API keys. CurseForge is not used by this release; if it is added, the key belongs
  only in the helper's build from the GitHub secret, and its terms for a separately distributed
  app must be confirmed first.
* Mod redistribution: export never assumes a mod may be redistributed; provider-hosted files are
  referenced, not bundled, and files whose authors disallow distribution are left out.
