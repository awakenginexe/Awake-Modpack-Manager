# Awake Modpack Manager 1.3.3

Works with **Awake Launcher 3.2.2**. No Launcher update is needed.

## Fixed

- **Changes kept getting rolled back with "Applied metadata did not verify."** After applying, the helper re-checks every tracked mod, not only the ones that changed. If any mod's jar no longer matched what the helper recorded, for example because a different build of that mod was copied into the pack, every apply was rolled back, even one that only installed an unrelated mod. Review & apply now warns about this before you apply. It lists the mods changed outside the Manager and offers two fixes:
  - **Restore originals** downloads the recorded file again and puts it back only if its hashes match the record exactly. Your changed file is copied first to `%LOCALAPPDATA%\AwakeModpackManager\policy-backups\`. If the download doesn't match, nothing changes.
  - **Keep my files** leaves your file as it is and stops tracking it. Use this when a pack ships its own build of a mod on purpose. The Manager won't offer updates for that mod any more.

## Changed

- **History lists the newest operation first.**
- **History shows which mods each change touched:** installed, removed, updated (old → new version), enabled or disabled. A change that failed or was rolled back is labelled as not applied. Long lists start folded. The list is kept on this computer for the last 200 applies. Changes made before 1.3.3 have no list, because the helper never recorded mod names.
