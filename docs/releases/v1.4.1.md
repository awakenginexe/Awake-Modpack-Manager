# Awake Modpack Manager 1.4.1

Works with **Awake Launcher 3.2.2** and newer.

## New

- **YouTube videos play on a project's page.** A YouTube video embedded in a mod, resource pack or shader description now plays in the project window. Other embedded pages are shown as a link; clicking it asks first, then opens it in your browser.
- **Your search stays when you come back.** What you typed on Browse (mods, resource packs and shaders, each separately) is kept while the Manager is open, so switching to another page and back no longer clears it.

## Fixed

- **Blurry screenshots on Modrinth project pages.** The large preview used Modrinth's small thumbnail; it now loads the original image. The strip under it still uses the small one, on both sites.

## Safety

Only YouTube can play inside the Manager. The player address is rebuilt from the video's id (the author's address is never used as is), it uses YouTube's no-cookie domain, runs in a sandbox that cannot navigate the Manager's window, and the app's content policy allows frames from that one domain only.

## Not verified on a real machine yet

Checked with the automated tests and the built-in demo data. Still unverified in the desktop app: a real YouTube video playing in the project window, and full-size Modrinth screenshots.
