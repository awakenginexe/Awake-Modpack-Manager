# Awake Modpack Manager 1.2.3

Works with **Awake Launcher 3.2.2**.

## Added

- **Refresh on the Mods page.** Reads the mods folder again, so files you added or removed outside the Manager show up without restarting.
- **"Clean up missing mods" when a check is refused.** If a mod the pack tracks was deleted outside the Manager, "Check plan" used to fail every time with "A tracked file is missing". The message now explains this and offers one click to forget those mods and check again. No mod file is touched, and the previous records are kept as a backup in the Manager's data folder under `policy-backups`.
