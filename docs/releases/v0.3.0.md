# Awake Modpack Manager v0.3.0

Built on Awake Native Core 0.3.0. Requires Windows 10/11 x64.

## Install whole modpacks

**Get a modpack** now works. Search **Modrinth, CurseForge, FTB, ATLauncher and Technic**, choose a version, and the Manager downloads, verifies and installs it as a new project. Installing shows each stage and can be cancelled. A failed install leaves no empty project behind.

Projects remember their pack. When the pack has a newer version for the same Minecraft version, the project card offers **Update**. The whole change goes through Review first. Files the pack dropped are removed, a newer build of the same loader is applied, and mods you added yourself stay.

## Delete things for real

* **Projects:** right-click or use the **…** button. This permanently removes the project's files and catalog entry after you type its name. Several can be selected and deleted together. If a game or another program is using the project, nothing is removed and you are told why.
* **Rename** projects, including the name Awake Launcher shows for a linked project.
* **Files page:** browse a project's configs, resource packs and shaders, open their folders, and move files to the Recycle Bin.
* **Instances owned by Awake Launcher are never deleted from the Manager.** The menu says to manage them there.

## A real desktop app

* A new title bar in the Awake Launcher style, with back and forward navigation, window controls, and running-work and update indicators.
* Right-click menus on projects, mods, search results, modpacks and files.
* Native-feeling dialogs and notifications instead of browser ones.
* Keyboard and mouse: Ctrl+F search, Delete to remove the selection, F5 refresh, Alt+Left/Right and the mouse side buttons to navigate, Ctrl+, for settings.
* The window remembers its size and position, a second launch focuses the running window, and browser behaviours such as text-selecting the interface, page reload and the browser menu are gone.

## Browsing mods

* **CurseForge icons are fixed.** The cause was in Native Core, which only accepted images from CurseForge's download hosts while project logos live on its media host.
* **CurseForge search is most popular first**, instead of an arbitrary order.
* **Click a mod card** for a details panel with its author, downloads, license, categories, last update and every compatible version.

## Updates

* **The Manager updates itself from official GitHub releases.** It tells you when a version is out, shows the notes, and installs it after checking the download against the checksums published with that release. Portable copies are sent to the release page. Beta versions are opt-in under Settings → About.
* **Mod updates are much faster and no longer delay the list.** They use batched provider requests after the mods are on screen. The Mods page has **Check for updates** and **Update all** buttons.

## Large modpacks

Reading a project's mod list is now close to instant once its files have been hashed (a 311-mod pack shows in under a second). Mod and pack downloads run in parallel, and pack metadata is read in batches. Project lists no longer fail while one project is busy. One mod listing more than 512 game versions used to break a whole search page; that is fixed.

## Known limitations

* The installer and helper are not code-signed, so Windows SmartScreen may warn. In-app updates verify a SHA-256 published with the release; that protects against a damaged or swapped download, not a compromised GitHub account.
* **CurseForge files whose authors disallow third-party downloads** cannot be fetched automatically. They are listed after the install so you can download them yourself. If a whole pack disallows it, the Manager links to its page.
* **ATLauncher and Technic:** files are imported as local files, so they update only by installing a newer pack version. Packs that patch the Minecraft JAR directly (mostly very old ones) cannot be represented and are refused with that reason; use Awake Launcher for those.
* A pack update that changes the Minecraft version needs a new project.
* Packs are limited to 1 GiB per archive. FTB packs are not affected because the helper downloads their files directly.
* Deleting a project is permanent by design and does not use the Recycle Bin.
