# Awake Modpack Manager v1.0.0

The first stable release. Built on Awake Native Core 0.3.0. Requires Windows 10/11 x64. To play Manager projects in Awake Launcher, use Launcher 3.1.0 or newer.

## New in 1.0.0

* **Lists load as you scroll.** Browse and Get a modpack fetch the next page automatically, so there's no Load more button to press. Pages are requested at least 1.5 seconds apart to stay well within Modrinth and CurseForge limits. If a provider returns an error, loading stops and a **Load more** button lets you retry.
* **Compact and Custom Launcher installs now connect.** Awake Launcher only shares a data folder that other Windows accounts can't change, and a folder on a drive other than `C:` usually allows that. The Manager used to show "Waiting for Awake Launcher" forever. It now explains the problem and offers **Make folder private**.

### Using Make folder private

After you confirm, the folder gets the same permissions as a normal Launcher install. Your instances, mods and worlds aren't changed, but other Windows accounts on the PC lose access to that folder. Close Awake Launcher and open it again to connect.

## Everything from 0.3.0 is included

Modpack installs from Modrinth, CurseForge, FTB, ATLauncher and Technic, reviewed pack updates, project management, in-app updates and fast large-pack handling. See the [0.3.0 notes](v0.3.0.md).

## Known limitations

* The installer and helper are not code-signed, so Windows SmartScreen may warn. In-app updates verify a SHA-256 published with the release; that protects against a damaged or swapped download, not a compromised GitHub account.
* **CurseForge files whose authors disallow third-party downloads** cannot be fetched automatically. They are listed after the install so you can download them yourself.
* **ATLauncher and Technic:** files are imported as local files, so they update only by installing a newer pack version. Packs that patch the Minecraft JAR directly are refused with that reason.
* A pack update that changes the Minecraft version needs a new project.
* Packs are limited to 1 GiB per archive. FTB packs are not affected.
* Deleting a project is permanent by design and does not use the Recycle Bin.
* A Launcher data folder owned by another Windows account can't be made private from the Manager. Take ownership of it first, or move the Launcher data to a folder you created.
