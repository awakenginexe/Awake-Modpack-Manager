# Awake Modpack Manager 1.1.1

Needs **Awake Launcher 3.2.1** to manage Launcher packs.

## New

- **Update in one click.** **Update now** in Settings and the update button in the title bar start the update straight away. **Details** still shows what's new.
- **Searchable version lists.** Type `1.20` and pick `1.20.1` instead of scrolling. Works with the arrow keys and Enter.

## Fixed

- **Manage here works on more PCs.** It could fail with "Windows error 50", then say another program coordinates the instance.
- **A pack that hit that error can be managed again.** Update Awake Launcher to 3.2.1 first. It restores the pack the next time it starts, and your mods and worlds were not changed.
