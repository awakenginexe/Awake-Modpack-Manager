# Awake Modpack Manager 1.3.4

Works with **Awake Launcher 3.2.2** and newer. Launcher 3.2.4 can rename an instance; this release follows that name.

## Fixed

- **A Launcher instance managed here kept its old name after it was renamed in Awake Launcher.** The Manager showed the name it saved when you chose "Manage here". It now shows the name the Launcher has.
- **The instance list refreshes when you come back to the Manager window**, so an instance renamed, added or removed in Awake Launcher shows up without a restart. F5 still refreshes too.

## Changed

- **Rename on a Launcher instance explains where to do it.** The disabled menu item now says to rename it in Awake Launcher. The Launcher does not let the Manager rename its instances yet.

## Not verified on a real machine yet

The automated tests cover the name. Still unverified: the refresh on window focus in the desktop app against a real Launcher.
