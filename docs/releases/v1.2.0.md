# Awake Modpack Manager 1.2.0

Works with **Awake Launcher 3.2.1**.

## New

- **Choose your export format first.** Each format shows how many of your mods fit, and the Manager recommends the best one.
- **Instance (.zip).** A new format with every mod file inside, so any mix of Modrinth, CurseForge and manual mods works. Use it for backups or sharing privately, and get each author's permission before uploading it publicly.
- **Find mods on the other site, in place.** When a mod doesn't fit the format, the Manager looks for the identical file. For the rest you can search right there, pick a version, or leave the mod out.
- **Stop managing here** is now on the Mods page too.
- **Progress while a pack connects.** A status bar shows what the Manager is doing while it connects or hands back a pack.

## Faster

- CurseForge and Instance zips no longer look up every mod online before exporting.

## Fixed

- **Exporting no longer stops at a restricted mod.** Mods whose authors turned off third-party distribution stay in CurseForge zips, and a list shows which ones players must download themselves.
- **In-app updates no longer wait on the background helper.** The installer could sit on one screen for a long time with no explanation. It now starts after the helper has stopped, and says so if it does have to wait.

## Good to know

- An update from 1.1.1 still uses the old update steps once, so it can wait on that screen. Closing the Manager and running Setup avoids that.
- A `.mrpack` can only use Modrinth, GitHub and GitLab download links, so it can't contain CurseForge mods that have no identical file on Modrinth.
- `.mrpack` exports still look up each mod online, so they are slower than the other two formats.
