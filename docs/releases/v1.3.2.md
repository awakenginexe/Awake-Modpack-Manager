# Awake Modpack Manager 1.3.2

Works with **Awake Launcher 3.2.2**. No Launcher update is needed.

## Added

- **Mods that can only be downloaded from the CurseForge website.** Some authors turn off third-party distribution, and checking a plan with one of their mods used to stop at "CurseForge project does not allow third-party distribution". The Review page now lists those mods with an **Open download page** button: CurseForge starts the download after a few seconds, the Manager notices the file in your Downloads folder, moves it into the pack and takes the install out of the draft. Check the plan again for the rest of the draft.
- **Open all** opens every download page at once when there is more than one.
- **Choose downloaded file…** is for a download that went somewhere else, or a Downloads folder that is not in its usual place.

## How it behaves

- A file is taken only if its SHA-1 is the one CurseForge lists for that exact version, whatever the browser named it. Anything else in Downloads is left alone, and so is a download still in progress.
- Nothing in `mods` is overwritten. If another file already has the name, the download stays where it is.
- The Downloads folder is only looked at while the Review page is waiting for one of these files.
- A mod added this way shows as a manually added file: the helper does not track it, so the Manager does not offer updates for it. A CurseForge export still recognises it by its fingerprint.
- Only mods in your draft are offered. A restricted mod that is pulled in as a dependency still stops the check; add it to the draft yourself to get its download button.

## Not verified on a real machine yet

The demo data and the automated tests cover the Review page, and the host's file matching and move have their own tests. Still unverified: the whole flow in the desktop app against CurseForge and a real Downloads folder.
