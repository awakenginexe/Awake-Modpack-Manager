# Awake Modpack Manager 1.3.0

Works with **Awake Launcher 3.2.2**. No Launcher update is needed.

## Added

- **Files works, for Launcher instances too.** The Files page used to answer "The Manager helper in this build does not support file listing yet" for every Launcher instance managed here, and was read-only everywhere else. It now shows the configs, default configs, KubeJS, scripts, resource packs and shader packs of any instance you manage here, one folder at a time, with a filter for the folder on screen.
- **Edit configs and scripts in place.** Click a text file to open it, change it and save (Ctrl+S). A save never overwrites a file that changed on disk while it was open, for example a config the game rewrote: you are told and can open the new version. Windows line endings are kept. Files over 2 MB and files that are not text are left to other programs.
- **Add files and remove them.** "Add files" copies files you pick into the folder on screen and never replaces one that is already there. Removing still goes to the Windows Recycle Bin, after a confirmation.
- **Browse resource packs and shaders.** Browse now has three shelves in the sidebar: Mods, Resource packs and Shaders. The two new ones search Modrinth and CurseForge, can be limited to the instance's Minecraft version, show each version with its file, size and (for shaders) what loads it, and install with one click.

## How resource packs and shaders install

They are zip files the game only reads, with no loader or dependencies to resolve, so they do not go through "Review & apply". An install is one download from the provider's own CDN, checked against the provider's checksum, written under a temporary name and then moved into `resourcepacks` or `shaderpacks`. Installing a version whose file is already there replaces that file. Nothing else in the pack changes, and mods still only change through a reviewed plan.

Shaders need a shader mod in the pack, such as Iris or Oculus. Resource packs and shaders are turned on in the game's own options.

CurseForge authors can turn off downloads outside the CurseForge website. For those, the Manager says so and links the page: download it there and use "Add files".

## Changed

- Files no longer shows "included in export" for Manager projects and managed instances: their exports take these folders whole (Instance zip) or from the pack archive, so the tick boxes did nothing there.
- The Files and Browse pages tell you to turn on "Manage mods here" for a Launcher instance that is not managed here yet, instead of "Not available in this version yet".

## Safety

- The Manager's desktop host now writes inside six content folders of an instance (`config`, `defaultconfigs`, `kubejs`, `scripts`, `resourcepacks`, `shaderpacks`), and only when you save, add, install or remove something. It never writes to `mods`, worlds or anything else.
- A link or junction inside one of those folders is never followed, so nothing can be read, saved or removed outside them.
- Only a file whose name ends in `.zip` is ever installed from a provider.
