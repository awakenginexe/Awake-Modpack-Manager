# Awake Modpack Manager 1.1.0

Needs **Awake Launcher 3.2.0** for the Launcher features below. With an older Launcher, its instances stay read-only.

## New

- **Manage your existing Awake Launcher modpacks.** Choose **Manage here** on a pack to update, add, remove, enable and disable its mods with the same review, backup and rollback as Manager projects. Your files stay in the Launcher's folder, and you can stop at any time.
- **Browse mods for those packs** from Modrinth and CurseForge.
- **Play from the Manager.** The Play button starts the pack in Awake Launcher.
- **Instance images** from Awake Launcher now show in the Manager.

## Fixed

- ATLauncher packs show their images in Get modpack, and the empty "by" line is gone.

## Good to know

- While a pack is managed here, its mods can't be changed in Awake Launcher. It still plays from the Launcher with the same Java and memory settings.
- Mods without provider details are listed as manual files. You can remove or disable them, but the Manager can't look up updates for them.
- The Files page isn't available yet for packs managed from the Launcher.
- Large packs load slowly on the Mods screen. Listing 400 mods took about 26 seconds in testing.
