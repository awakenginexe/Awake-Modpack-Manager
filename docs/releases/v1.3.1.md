# Awake Modpack Manager 1.3.1

Works with **Awake Launcher 3.2.2**. No Launcher update is needed.

## Added

- **View images on the Files page.** Clicking a picture (`.png`, `.jpg`, `.jpeg`, `.gif`, `.webp`, `.bmp`, `.ico`) now opens it inside the Manager, the same way a text file opens in the editor, instead of answering "This is not a text file". The viewer shows the picture's size in pixels and on disk, fits large pictures to the window, enlarges small textures with sharp pixels, and draws transparent areas over a checkerboard. Pictures are listed with their own icon, and the right-click menu says "View" for them.

## How it behaves

- Pictures are only shown, never changed: there is nothing to save, so going back to the folder never asks.
- A file is shown only if its first bytes are those of a picture format the viewer knows, whatever its name ends in. Anything else is refused with a message.
- Pictures over 16 MB are left to other programs. A picture that is damaged says so instead of showing an empty frame.
- `.svg` files are text and still open in the editor.

## Safety

- The viewer reads through the same path checks as the editor: inside the six content folders only, and never through a link or junction.

## Not verified on a real machine yet

The demo data and the automated tests cover the viewer, and the host's reading and format check have their own tests. Still unverified: the viewer in the desktop app against a real instance.
