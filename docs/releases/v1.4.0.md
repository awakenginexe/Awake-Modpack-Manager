# Awake Modpack Manager 1.4.0

Works with **Awake Launcher 3.2.2** and newer.

## New

- **Turn a mod on or off with one click.** Every row on the Mods page has a switch. It is applied at once: no draft, no Review page. The change still goes through the same check, backup and rollback as a reviewed draft. If a switch would affect other mods (a conflict, or another mod pulled in), it is not applied silently: it is put in your draft and a message says so. A draft you were already building is kept.
- **A full project page when you click a mod, resource pack or shader.** Instead of the narrow panel on the right, a window opens with the project's own description and screenshots from Modrinth or CurseForge on the left, and the versions, the install or "Add to draft" button and "Open project page" on the right.

## Changed

- The mods table always shows the switch; on a narrow window it drops the Dependencies column instead.
- "Enable" and "Disable" in a mod's right-click menu and details panel are applied at once too. Enabling or disabling several selected mods still goes through the draft.

## Fixed

- **An instance managed here could show as "Read-only", and "Manage mods here" answered "This instance is already managed here."** This happened when the Manager's helper could not list its instances (for example after a jar saved from a browser was dropped into the mods folder). The Manager hid that error and treated the instance as unmanaged. It now shows the helper's message under the instance list and on "Manage mods here". The helper's own fix for browser-saved jars is separate and ships with a newer helper.

## Safety

Project descriptions are written by anyone on the two sites. They are never inserted as HTML: only plain formatting, https links and https images are rebuilt from them, and links open in your browser. Images in a description load from the address the author used.

## Not verified on a real machine yet

Checked with the automated tests and the built-in demo data. Still unverified in the desktop app against a real instance: the switch on a large pack, and real Modrinth and CurseForge project pages (descriptions, screenshots).
