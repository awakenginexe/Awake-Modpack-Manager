# Awake Modpack Manager 1.2.2

Works with **Awake Launcher 3.2.2**.

## Fixed

- **"Update draft" works after "The instance changed after your review".** The Manager now re-reads the instance before updating the draft, so the next "Check plan" goes through instead of showing the same message again.
- **"Check plan" no longer stops just because the instance changed.** If the Launcher or a game run changed the instance since you built the draft, the Manager re-reads it and checks the plan against the current state. It still stops and asks when the change makes part of your draft pointless.
