# Awake Modpack Manager 1.2.1

Works with **Awake Launcher 3.2.2**.

## Fixed

- **CurseForge mods install again.** Installing from CurseForge could fail with "CurseForge request failed (HTTP 302)".
- **The same mod from two sites no longer blocks a change.** If a required mod is already in the pack from Modrinth or CurseForge, the identical file from the other site is not added again. "Things to check" tells you when this happens.
- When two mods really would use the same file, the message now names them.
- **"Ready to apply" no longer looks stuck.** A checked plan is waiting for you, so History shows it as waiting, with a button back to it when it is still open.
- **Abandoned plans clean up.** Discarding a draft, or undoing all of it, cancels its checked plan.
- **Cancel updates History straight away.**

## New

- Each mod in your draft shows which site it comes from.

## Good to know

- An update from 1.1.1 still uses the old update steps once, so it can wait on the installer screen. Closing the Manager and running Setup avoids that.
