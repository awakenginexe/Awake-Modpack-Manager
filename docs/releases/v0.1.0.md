First public release of **Awake Modpack Manager**: a Windows app for building and maintaining
Minecraft modpacks from Modrinth, with every change reviewed before it is applied. Awake Launcher
is not required.

## Download

| File | What it is |
|---|---|
| `Awake-Modpack-Manager-v0.1.0-Windows-x64-Setup.exe` | Installer for Windows 10/11 x64 (per-user, no admin rights) |
| `SHA256SUMS.txt` | SHA-256 checksums of the files in this release |
| `Awake-Native-Core-299c140bd-Source.zip` | Complete source of the bundled native helper (GPL-3.0-only) |

The installer is **not code-signed**. Windows SmartScreen may show "unknown publisher": compare
the checksum first (`Get-FileHash .\Awake-Modpack-Manager-v0.1.0-Windows-x64-Setup.exe`), then
choose **More info → Run anyway**.

## What works

* Create standalone modpack projects with an exact Minecraft version, mod loader (vanilla or
  Fabric) and loader version.
* Search Modrinth and choose an exact compatible mod version.
* Real installation: files are downloaded and verified (size, SHA-512, SHA-1) before anything in
  your project changes.
* Required dependencies are added automatically and shown in the review.
* Update, disable, enable and remove mods, each through Review & apply.
* Transaction safety: Apply is refused if the project changed since review; interrupted changes are
  rolled back or completed on restart; History shows every operation, error and recovery step.
* English, Thai, Simplified Chinese and Traditional Chinese.

## Known limitations

* CurseForge search and downloads are not available yet (Modrinth only).
* Shared Awake Launcher instances are not supported; they can only be viewed read-only.
* The Manager does not launch Minecraft.
* Vanilla and Fabric only; not every Minecraft version or loader is supported, and dependency
  checks rely on the metadata authors publish.
* Modpack catalogs and import/export through the helper are not available; the Projects page's
  `.mrpack`/CurseForge ZIP preview and draft export work as before.
* Mods are listed by file name.
* The installer is unsigned.

Your projects live in `%LOCALAPPDATA%\AwakeModpackManager` and are kept when you upgrade or
uninstall.
